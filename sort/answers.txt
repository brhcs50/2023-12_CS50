sort1 uses: Bubble Sort

How do you know?: Bubble Sort has O(n^2) and Omega(n), meaning that if the file is already sorted, it will be much faster than non-sorted files.
    This is the case according to the times I collected below.

sort2 uses: Merge Sort

How do you know?: Merge Sort has O(n log n) and Omega(n log n).
    Sorting will be the fastest on a random list, as shown in the times I collected.

sort3 uses: Selection Sort

How do you know?: Selection Sort has O(n^2) and Omega(n^2).
    Regardless of the file, the sorting will be slow, but a pre-sorted file will not gain any benefit.



// -- sort1 times
